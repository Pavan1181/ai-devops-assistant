# 🤖 AI DevOps Assistant

An AI-powered DevOps troubleshooting assistant built using Python,
Streamlit, Groq LLM, and Docker.

## 🚀 Features

- 💬 AI-powered DevOps chatbot
- 🐧 Linux troubleshooting
- ☁️ AWS troubleshooting and explanations
- 🐳 Docker troubleshooting
- 📋 DevOps log analyzer
- 🔍 Error root-cause analysis
- 🛠️ Step-by-step troubleshooting solutions
- 📦 Dockerized application
- 🌐 Streamlit web interface

## 🛠️ Technologies Used

- Python
- Streamlit
- Groq API
- Docker
- Git & GitHub
- Linux
- AWS concepts
